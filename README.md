# 블랙홀 (Black Hole)

손가락으로 블랙홀을 움직여 소행성부터 은하단까지 삼키는 모바일 웹 미니게임.

**플레이:** https://edibulb.github.io/blackhole/

## 규칙
- 화면을 누른 채 끌어서 블랙홀을 이동
- 하늘색 테두리 천체는 삼킬 수 있고, 주황 점선 천체는 나보다 커서 닿으면 작아짐
- 계속 먹지 않으면 블랙홀이 줄어들다 사라짐
- 3분 안에 '우주 전체' 단계에 도달하면 클리어

## 아이템
- 중력 증폭: 5초간 빨아들이는 범위 2배
- 보호막: 큰 천체에 한 번 닿아도 안 줄어듦
- 시간 정지: 5초간 블랙홀이 줄어들지 않음

## 기술
- [Phaser 3](https://phaser.io/) (CDN)
- 천체 그래픽은 SVG로 그려 런타임에 텍스처로 변환 (이미지 파일 없음)
- 단일 `index.html`, 빌드 과정 없음
